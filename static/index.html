Settings

Appearance

Applies across the whole app, including the 3D graph and Archive Connections.

Similarity scores

Computes a pairwise similarity score between every reference in your library, using the CLIP embeddings already generated for each one -- no additional Claude API calls. Saved for later use (e.g. a 3D similarity graph); nothing in the app reads these yet.

Colour analysis

New images are analysed for colour automatically as they're added. This doesn't recompute the colourspace graph -- positions there are derived from stored profiles each time it's opened, so there's nothing to rebuild. It fills in profiles for images that don't have a current one: ones added before colour analysis existed, ones whose file has changed since, and ones analysed under an older version of the algorithm.

Travel between locations

Each location's "Travel from home" above covers the first and last leg of a day -- home to a location and back. It can't express a trip between two locations directly, so add the pairs actually travelled here. A pair with no row falls back to going via home (deliberately pessimistic -- there are no coordinates in this system and no routing API; if that produces a silly number, add the pair instead of guessing at a distance). Travel is treated as symmetric by default, so adding a pair offers to save both directions at once.

Calendar import

From a file

A studio timetable exported as .ics. Events are matched on their calendar UID, so uploading the same (updated) file again updates existing commitments and removes any that are no longer in it, instead of duplicating everything.

From a feed URL

A live calendar feed. The URL is remembered after the first import, so re-syncing later is just Re-sync -- no need to paste it again.

Personal events

Going out, a haircut, a train -- time that's simply taken, not work to schedule. No estimate, nothing generated: a title, when, and optionally where. They're immovable, and may sit anywhere, including outside working hours.
